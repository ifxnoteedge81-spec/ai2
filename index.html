Install

  1. Download the APK on your Android phone (Android 8.0 or newer).
  2. Optional: verify the SHA-256 above (for example with a checksum app) to make sure the file is intact.
  3. Open the file. Android will ask you to allow installs from your browser or file manager; allow it for this one install.
  4. Open the app, go to AI Model Settings, and add your own Gemini or OpenRouter API key.
  5. To let the agent operate other apps, enable Virtual Hands in Android Accessibility settings (on Android 13+ you may first need App info → ⋮ → Allow restricted settings).

A build marked "debug" is signed with a debug key because the project owner has not configured release-signing secrets yet. It works, but it is not a production-signed release.
